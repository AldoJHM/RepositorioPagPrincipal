Cascading Style Sheets "CSS".

¿Qué es CSS?

CSS (Cascading Style Sheets) es un lenguaje de diseño utilizado para dar estilo a documentos HTML. Permite controlar el aspecto y la presentación de múltiples páginas web al mismo tiempo.

Con CSS, puedes definir el color, la fuente, el tamaño y el espaciado del texto, así como el diseño, la ubicación y otros aspectos visuales de los elementos en una página web. Además, CSS permite crear diseños responsivos que se adaptan a diferentes dispositivos y tamaños de pantalla.

Una de las principales ventajas de CSS es su capacidad de cascada, lo que significa que puedes definir estilos en diferentes niveles y capas, y los estilos se aplicarán de acuerdo con la especificidad y la herencia.

En resumen, CSS es una herramienta poderosa que permite dar estilo y diseño a las páginas web, lo que mejora la experiencia del usuario y la apariencia visual de un sitio web.

Sintaxis y Estructura de una Regla CSS

Una regla CSS consta de dos partes principales: un selector y un bloque de declaración.

Selector

El selector es el elemento al que se aplicarán los estilos. Puede ser el nombre de un elemento HTML, una clase, un identificador, o una combinación de estos.

Ejemplos de selectores:

  • Elemento HTML: p { /* Estilos */ }
  • Clase: .clase { /* Estilos */ }
  • Identificador: #id { /* Estilos */ }
  • Selector de atributo: [atributo="valor"] { /* Estilos */ }

Bloque de Declaración

El bloque de declaración contiene una o más propiedades y sus valores separados por dos puntos (:), cada declaración separada por punto y coma (;).

Ejemplo de un bloque de declaración:

        
            {
                propiedad1: valor1;
                propiedad2: valor2;
                propiedad3: valor3;
                /* Más propiedades y valores */
            }

Es importante recordar que las reglas CSS pueden anidarse dentro de otras reglas y que los estilos se aplicarán según la cascada y la especificidad.

Tipos de Selectores CSS

En CSS, hay varios tipos de selectores que se utilizan para aplicar estilos a elementos específicos en una página web. Algunos de los tipos de selectores más comunes son:

Selectores Simples

Los selectores simples se utilizan para seleccionar elementos HTML específicos basados en su nombre, clase o ID.

            
                /* Selector de elemento */
                p {
                    /* Estilos para párrafos */
                }
    
                /* Selector de clase */
                .clase {
                    /* Estilos para elementos con la clase 'clase' */
                }
    
                /* Selector de ID */
                #id {
                    /* Estilos para elementos con el ID 'id' */
                }

Selectores Combinadores

Los selectores combinadores se utilizan para seleccionar elementos basados en su relación con otros elementos.

            
                /* Selector de descendencia */
                div p {
                    /* Estilos para párrafos dentro de divs */
                }
    
                /* Selector de hijo directo */
                ul > li {
                    /* Estilos para elementos que son hijos directos de  */
                }
    
                /* Selector de hermano adyacente */
                h2 + p {
                    /* Estilos para párrafos que son hermanos adyacentes de h2 */
                }

Selectores de Pseudoclase

Los selectores de pseudoclase se utilizan para aplicar estilos a un elemento en función de su estado o interacción del usuario.

        
            /* Selector de enlace no visitado */
            a:link {
                /* Estilos para enlaces no visitados */
            }

            /* Selector de enlace visitado */
            a:visited {
                /* Estilos para enlaces visitados */
            }

            /* Selector de elemento activo */
            button:active {
                /* Estilos para botones activos */
            }

Selectores de Pseudoelementos

Los selectores de pseudoelementos se utilizan para aplicar estilos a partes específicas de un elemento.

        
            /* Selector de primer elemento hijo */
            p:first-child {
                /* Estilos para el primer párrafo dentro de su contenedor */
            }

            /* Selector de primer línea de texto */
            p::first-line {
                /* Estilos para la primera línea de texto en párrafos */
            }

            /* Selector de primer letra */
            p::first-letter {
                /* Estilos para la primera letra en párrafos */
            }

Selectores de Atributos

Los selectores de atributos se utilizan para aplicar estilos a elementos que tengan un atributo específico. 

        
            /* Selector de atributo específico */
            input[type="text"] {
                /* Estilos para inputs de tipo texto */
            }

            /* Selector de atributo que comienza con un valor específico */
            a[href^="https"] {
                /* Estilos para enlaces con href que comiencen con "https" */
            }

            /* Selector de atributo que contiene un valor específico */
            img[alt*="imagen"] {
                /* Estilos para imágenes con alt que contengan "imagen" */
            }

Formas de Insertar CSS en una Página HTML

Existen varias formas de incluir CSS en una página HTML. Algunas de las formas más comunes son:

  • Etiqueta <style>: Puedes incluir CSS directamente en el <head> de tu documento HTML utilizando la etiqueta <style>.
  • Archivo Externo: También puedes enlazar un archivo CSS externo utilizando la etiqueta <link> dentro del <head> de tu documento HTML.
  • Atributo style: Además, puedes aplicar estilos directamente a elementos HTML utilizando el atributo style.
